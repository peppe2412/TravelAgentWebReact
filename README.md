# Travel Agent React + Vite
### Un Assistente Ai che permette di consigliare viaggi, in base all'esigenze degli utenti
#### In questo progetto è stato ultilizzato l'API del progetto [TravelAgentApi](https://github.com/peppe2412/ProgettoTravelAgentApi)
## In questo progetto sono stati utilizzati diversi pacchetti:
- [React router](https://reactrouter.com/home):
  ```
  npm install react-router-dom
  ```
- [Axios](https://axios-http.com/docs/intro):
  ```
  npm install axios
  ```
- [React Markdown](https://github.com/remarkjs/react-markdown?tab=readme-ov-file#install):
  ```
  npm install react-markdown
  ```
- [Font Awesome](https://fontawesome.com/):
  ```
  npm install @fortawesome/fontawesome-svg-core \
            @fortawesome/free-solid-svg-icons \
            @fortawesome/free-brands-svg-icons \
            @fortawesome/react-fontawesome
  ```
